# Prompt Library

## Prompt Templates

### Agent Invocation Template
```
Context:
- Phase: [phase]
- Feature: [feature]
- Current state: [what's happening]

Task:
[describe the task clearly]

Files to read:
- [file paths]

Files to modify:
- [file paths]

Constraints:
- [any rules or constraints]

Output:
- [expected output format]
```

```
Current state: [summary]
Phase: [phase]
Next expected action: [what Production Level says should happen]
Options:
1. [option] — [why]
2. [option] — [why]

```
