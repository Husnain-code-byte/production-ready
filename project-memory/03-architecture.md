## Architecture Principles
1. **API-first:** contract defined before implementation
2. **Stateless services:** no server-side session state
3. **Eventual consistency where acceptable:** strong consistency only when required
4. **Defense in depth:** security at every layer
5. **Observability built-in:** every service emits traces, metrics, and logs
6. **Fail gracefully:** circuit breakers, retries with backoff, graceful degradation
7. **Serial execution guarantee:** Agents are invoked sequentially by the human architect — never in parallel. `project-memory/` files are written by one agent at a time. No concurrent writes, no race conditions, no file-level locking needed.
8. **Memory reload on invocation:** Every agent reloads `project-memory/` at invocation. Cache invalidation is implicit — agents run sequentially, so no stale reads. If project-memory grows beyond ~200KB, introduce selective loading.
9. **Shared mutable state:** `project-memory/` is the single source of truth — shared across agents, mutable only through serial writes. Equivalent to a single-writer database — safe without locks under the serial execution guarantee.
