# Production Level — Native Google Antigravity Plugin

**Production Level** is an enterprise-grade, 9-phase AI software engineering harness packaged as a native Google Antigravity plugin.

## Included Customizations
- **26 Specialized Agents (`agents/*.md`):** Meta-orchestrator `aegis` + 25 domain specialists across vision, architecture, implementation, cross-model verification, hardening, and arbitration.
- **17 Slash-Command Skills (`skills/<name>/SKILL.md`):** `/start-session`, `/end-session`, `/phase-check`, `/scope-check`, `/spec-write`, `/verify-feature`, `/refactor-gate`, `/adr-write`, `/commit-format`, `/session-log`, `/context-update`, `/abort-feature`, `/parallel-discover`, `/rollback-feature`, `/cool-down`, `/checkpoint`, and `/restore`.
- **6 Lifecycle Hooks (`hooks.json`):** Native `SessionStart`, `PreToolUse`, `PostToolUse`, `PreInvocation`, `PostInvocation`, and `Stop` hooks.
- **Consolidated Rules (`rules/AGENTS.md`):** Core methodology invariants, red-flag auto-abort rules, multi-model routing, and 4-tier effort governance.
